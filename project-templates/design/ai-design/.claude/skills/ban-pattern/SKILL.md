# ban-pattern スキル

## 目的
開発中に発見した「AIっぽいパターン」をその場で禁止リストに追加し、
以降のUI生成で同じ問題が出ないようにする。

## 使い方
```
/ban-pattern shadow-lg を使ったカード
/ban-pattern カードヘッダーのカラーバー
/ban-pattern text-gradient の多用
```

## 手順

1. ユーザーから禁止したいパターンを受け取る
2. `.claude/rules/design.md` の禁止パターン表を読む
3. 新しい禁止パターンを適切なカテゴリに追加する：
   - 禁止するクラス名
   - 代替案
   - 理由（簡潔に）
4. ファイルを更新する
5. 追加内容を報告する

## 追加フォーマット
```markdown
| `禁止クラス名` | 代替クラス名またはNG理由 |
```

## 注意
- 禁止パターンは増やしすぎると逆効果（AIが守れなくなる）
- 追加する前に既存パターンと重複しないか確認する
- 具体的なクラス名またはコードパターンで記述する
