# anti-human-bottleneck スキル

## 目的
ループエージェントが人間を待たずに問題を自己解決できるようにする。
人間のレビュー待ちがループの最大のボトルネックになるため、これを排除する。

## 使い方
```
/anti-human-bottleneck
```
詰まったとき、人間に質問する前にこのスキルを実行する。

## 自己解決チェックリスト

### エラー・バグの場合
- [ ] エラーメッセージをすべて読んだか
- [ ] スタックトレースを追ったか
- [ ] 関連するソースコードを読んだか
- [ ] 公式ドキュメントファイル（docs/）を確認したか
- [ ] 類似の実装が既存コードにないか探したか
- [ ] 小さな再現コードを書いて原因を特定したか

### 設計判断の場合
- [ ] PROMPT.md のゴールから逆算して判断できないか
- [ ] 既存の実装パターンに合わせられないか
- [ ] より単純なアプローチが存在しないか
- [ ] トレードオフを `notes` に書いて進められないか

### 仕様不明の場合
- [ ] 既存のテストコードが仕様を示していないか
- [ ] 型定義・インターフェースから推測できないか
- [ ] コミット履歴・PR コメントから意図を読み取れないか

## それでも解決できない場合

以下のフォーマットで `progress.json` の `blockers` に記録して終了する：

```json
{
  "blocker": "問題の説明（1文）",
  "tried": ["試みたこと1", "試みたこと2"],
  "need_from_human": "人間に決めてほしいこと（具体的に）"
}
```

## 禁止パターン
- 「どうすればいいですか？」とだけ聞く → **禁止**
- 複数の選択肢を並べて人間に選ばせる → **禁止**
- 「確認させてください」で止まる → **禁止**

人間に聞くときは、**すでに試みたことのリスト** と **具体的に必要な情報** を添える。
