# design-review スキル

## 目的
AIが生成したUIの「一次品質チェック」を自動化する。
禁止パターン違反とトークン未使用箇所を洗い出す。

## チェック手順

### 1. 対象ファイルの特定
引数で指定されたファイル、または直近で変更されたUIファイルを対象とする。

### 2. 禁止パターンスキャン
`.claude/rules/design.md` の禁止パターンリストと照合する。

チェック項目:
- `text-black` の使用
- `shadow-lg` / `shadow-xl` / `shadow-2xl` の使用
- `border-l-4` カラーバーの使用
- `bg-blue-*` / `bg-indigo-*` のハードコード
- `bg-gradient-*` の使用（指示なし）
- 絵文字の過度な使用
- ハードコードカラー（`#xxxxxx` 直書き）

### 3. トークン参照チェック
- `tokens.json` にあるトークン名が使われているか
- Tailwindクラスに直接カラーコードが混入していないか

### 4. 「AIっぽさ」の主観的チェック
全体のビジュアルバランスを評価する：
- カードが重すぎる装飾になっていないか
- 情報の優先順位が視覚的に明確か
- 余白が適切か（詰めすぎ・広げすぎ）

## 出力フォーマット

```
## デザインレビュー結果

### 🔴 必須修正（禁止パターン違反）
- [ファイル:行番号] `shadow-lg` → `shadow-sm` に変更してください

### 🟡 推奨改善
- [ファイル:行番号] ハードコードカラー `#3B82F6` → `bg-primary-500` を使用してください

### ✅ 問題なし
デザインシステムルールに準拠しています。

### 総合評価
Approve / Request Changes
```

## 注意
このレビューはAIによる自動チェックです。
「AIっぽい」という感覚的な判断は最終的に人間が行ってください。
