# vuln-scan スキル

## スキャン対象
引数で指定されたファイルまたはディレクトリ全体をスキャンする。

## チェック項目

### OWASP Top 10 対応
1. **インジェクション** — SQLインジェクション・コマンドインジェクション・XSS
2. **認証の欠陥** — セッション管理・パスワード保存・JWT検証
3. **機密データの露出** — ハードコードされたシークレット・ログへの出力
4. **XXE** — XMLパーサーの設定
5. **アクセス制御の欠陥** — 権限チェックの漏れ・水平越権
6. **セキュリティ設定ミス** — デフォルト設定・不要な機能の有効化
7. **XSS** — ユーザー入力のエスケープ漏れ
8. **安全でないデシリアライズ** — 信頼できないデータのデシリアライズ
9. **既知の脆弱性のあるコンポーネント** — package.json の `npm audit`
10. **不十分なログ** — 重要操作のログ漏れ

## スキャン手順
1. Grep でパターンを検索（ハードコードシークレット・危険な関数）
2. `npm audit` を実行して依存関係の脆弱性を確認
3. 認証・権限チェックのコードを手動確認

## 出力フォーマット
```
## 脆弱性スキャン結果

### 🔴 高リスク（即時対応必要）
- [ファイル:行番号] 問題の説明 / 修正方法

### 🟡 中リスク（次スプリントで対応）
- [ファイル:行番号] 問題の説明 / 修正方法

### 🟢 低リスク（参考情報）
- ...

### ✅ 問題なし
- 確認した項目一覧
```

## ⚠️ 重要
このスキャンはAIによる自動チェックです。
高リスク項目は必ず人間のセキュリティレビューを実施してください。
