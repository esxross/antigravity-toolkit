# code-review スキル

## レビュー手順

1. 変更ファイルを特定する
2. 各ファイルを読んで変更の意図を把握する
3. 以下の観点でレビューする

## レビュー観点

### コード品質
- 型安全性（`any` の使用・型キャスト）
- エラーハンドリングの漏れ
- 重複コード・抽象化の機会
- 命名の明確さ

### セキュリティ（参照: `.claude/rules/security.md`）
- 入力バリデーション
- 認証・認可チェック
- 機密情報の扱い

### テスト
- 新機能にテストがあるか
- バグ修正に回帰テストがあるか

### パフォーマンス
- N+1クエリ
- 不要な再計算・再レンダリング

## 出力フォーマット

```
## コードレビュー

### 🔴 必須修正（マージ前）
- [ファイル:行番号] ...

### 🟡 推奨改善
- [ファイル:行番号] ...

### ✅ 良い点
- ...

### 総合評価
Approve / Request Changes
```
