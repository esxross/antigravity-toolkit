# セキュリティルール

## 入力バリデーション
- すべてのユーザー入力はzodでバリデーションする
- APIエンドポイントの入力は必ずスキーマ検証
- ファイルアップロードはMIMEタイプ・サイズ・拡張子を検証

## 認証・認可（必ず人間がレビュー）
- セッション管理は実績あるライブラリを使う（NextAuth.js等）
- JWTの署名検証を必ず行う
- 権限チェックはサーバー側で行う（クライアント側のみは禁止）

## データ操作（必ず人間がレビュー）
- SQLクエリはパラメータバインディング必須（文字列結合禁止）
- ORMを使う場合も raw query では必ずバインディング
- 一括削除・更新には必ず条件を指定する

## 機密情報
- APIキー・シークレットは環境変数のみ
- ログに機密情報を出力しない（パスワード・トークン）
- エラーレスポンスにスタックトレースを含めない（本番）

## 出力
- HTMLを直接生成する場合はXSSを防ぐエスケープを行う
- JSON APIレスポンスには不要なフィールドを含めない
- ファイルパスをユーザー入力から組み立てない（パストラバーサル）

## ⚠️ 人間レビュー必須
以下のコードはAIが生成した後、必ず人間が手動でレビューする：
- 認証フロー全体
- 決済処理
- ユーザーデータの削除・変更
- 権限管理ロジック
