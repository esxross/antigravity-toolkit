# Antigravity ツールキット

このプロジェクトは、AIアシスタント「Antigravity」を最大限に活用し、日々の開発作業やリサーチを効率化するための「知能の基地」です。

## プロジェクトの目的
- Antigravityへの指示（プロンプト）の標準化
- 頻繁に発生するワークフローの自動化定義
- プロジェクト固有のナレッジ管理

## 主要なファイル構成
- `CLAUDE.md`: AIアシスタントへの基本指示（性格、言語、コーディングルールなど）
- `.agents/workflows/`: 定型作業の手順書（Markdown形式）
- `task.md`: 進行中のタスク管理

## 使い方
Antigravity（私）に対して、「このプロジェクトのルールに従って作業して」と伝えることで、あらかじめ定義された高品質な応答が得られるようになります。
